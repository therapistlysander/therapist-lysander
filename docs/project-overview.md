# Project Overview

## About

A professional website for **Lysander Verschuur**, a trauma-informed psychologist/therapist based in the Netherlands. The application serves as both a public-facing website and an internal admin panel for practice management.

## Purpose

- Present professional information to potential clients
- Allow clients to book intro calls and submit pre-intake questionnaires
- Handle contact form inquiries
- Provide an admin CMS for managing all content, bookings, and settings

## Key Features

### Public Site
- Homepage with configurable sections
- About, Trauma Approach, Clinical Training pages
- Testimonials page
- FAQ page
- Fees & Process page
- Contact form with email notifications
- Booking system with availability calendar
- Pre-intake questionnaire

### Admin Panel
- Dashboard with statistics
- Booking management (approve/reject/schedule)
- Contact submission management with notes
- Pre-intake response review
- Content management (page sections, testimonials, FAQs)
- SEO settings per page
- Site-wide settings
- Media library
- Email/notification settings
- Availability schedule management
- Password management

## Target Users

1. **Potential clients** — Browse information, book sessions, fill pre-intake forms
2. **Lysander (admin)** — Manage bookings, content, settings, and communications

## Languages

The website supports both English and Dutch content, with language preference captured during booking.
